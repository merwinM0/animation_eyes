# 终端眼睛动画

默认使用白色 2×4 Unicode 盲文点阵绘制眼睛，纵向采样精度是原 2×2 象限块的两倍，动画目标为 60 FPS。保留终端默认背景色，右下角显示系统本地时间。

点阵显示需要字体支持 Unicode 盲文字符；喜欢实心眼睛或字体显示异常时，可按 `B` 切回原来的 2×2 象限块。两种模式均保留尺寸适配和差量更新。

## 运行

需要支持 Rust 2024 edition 的 stable 工具链（当前锁定依赖要求 Rust 1.85 或更新版本），以及支持 Unicode 的交互式终端：

```bash
cargo run
```

| 按键 | 功能 |
| --- | --- |
| 空格 | 依次预览下一种表情，暂停时也可切换 |
| `P` | 暂停 / 继续动画（时钟和尺寸适配仍正常工作） |
| `B` | 在高精度点阵与原实心块模式之间切换，暂停时也可使用 |
| `Q`、`Esc`、`Ctrl+C` | 退出，并恢复光标、换行和主屏幕 |

## 表情与动作

- 基础动作：眨眼、眯眼、左眼眨眼、右眼眨眼、惊讶睁眼、向上看、向下看。
- 情绪表情：委屈垂眼、生气斜眼、困倦半闭眼、疑惑大小眼；与基础动作合计 11 种。
- 随机调度避免连续重复，动作之间随机静止约 0.8～2.8 秒；长表情带有平滑过渡和短暂停留。
- 左右移动独立叠加，每 25 秒随机安排 3～4 次，每次约 1 秒；移动不会互相重叠。

## 终端适配与性能

- 监听终端尺寸变化，立即重新布局、清除旧位置残影；暂停期间也能调整大小。
- 双眼水平对称，基准线约为可用高度的 2/5；整张脸按宽高约束等比例缩放，宽而矮的窗口不会把眼睛压扁，并为表情变化和底部时钟预留空间。
- 过小的窗口改用紧凑 ASCII 表情；不足 5 列或 3 行时隐藏时钟，所有输出均限制在终端边界内。
- 每约 16.67ms 更新动画（目标 60 FPS）；按固定帧截止时间调度，绘制超预算时跳过过期帧，不积压旧帧或阻塞输入。
- 复用双帧和整帧输出缓冲，合并相邻变化与短间隔后批量提交；仅首次绘制或尺寸变化时清屏，静止帧不输出，切换显示模式也无需清屏。
- 只在眼睛包围盒内采样，每只眼睛预先换算采样偏移，避免在像素内循环反复做除法；合并一批缩放事件后再重绘。
- 底栏空间足够时显示当前动作、暂停状态及快捷键；时钟每秒检查一次，只显示小时和分钟。
- 实际帧率取决于终端、字体、窗口大小与机器性能；可用下方命令实测渲染计算与编码开销，不需要生成 release 产物。
- 只依赖 `chrono` 与 `crossterm`，不需要图片解码或终端图片协议依赖。

## 验证与调试

```bash
cargo fmt --all -- --check
cargo check --locked
cargo test --locked
cargo clippy --locked --all-targets -- -D warnings
```

测试覆盖表情调度、移动范围、点阵位序与精度、模式切换、窄屏与零尺寸、反复缩放、差量擦除、批量输出、60 FPS 帧调度、暂停计时和输入处理。

手动测量两种显示模式在 80×24、160×48、320×100 窗口下的渲染耗时与输出量：

```bash
cargo test --locked measure_render_throughput -- --ignored --nocapture
```

该测量不包含终端模拟器的实际绘制耗时，不把机器性能作为普通测试的通过条件。

日常 dev 构建仅保留堆栈行号，依赖不生成调试信息，以降低 `target/` 占用。需要调试器检查变量时，使用 `cargo build --profile debugging`。
