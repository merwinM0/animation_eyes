基准线 y = 高度 * 2 / 5
左眼起点 x = 宽度 * 1 / 4
右眼起点 x = 宽度 - 宽度 * 1 / 4 - 眼睛宽度
眼睛宽度 = 宽度 * 1 / 6
眼睛上下延伸高度 = 宽度 * 1 / 12

动态效果：
- 每 50ms 刷新一帧
- 使用 2x2 Unicode 象限块绘制眼睛，边缘比整格像素更细腻
- 眼睛动作由随机调度器控制，同一时间只执行一种眼睛动作
- 动作之间会随机留出约 0.8~2.8 秒的静止时间
- 动作类型包括：眨眼、眯眼、左眼眨眼、右眼眨眼、睁大眼睛、向上看、向下看
- 左右移动：每 25 秒随机触发 3~4 次，每次持续约 1 秒
- 左右移动是独立动作，可以发生在任意眼睛动作或眼睛不动时
- 右下角用白色显示系统本地时间，只显示小时和分钟
